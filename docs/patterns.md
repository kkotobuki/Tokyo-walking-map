# 街の横断パターン（システム理解の出力）

- 読者: このプロジェクトを進める本人。個別駅（L1）ではなく、駅を横断して見えてくるメタパターン（ADR-0002 の「なぜ東京はこうなったか」に当たる観察）を貯める場所。
- 位置づけ: 個々の駅ページ（Notion）が L1、この文書が「横断して立ち上がったパターン」。集計は `pnpm run stats` で再生成できる。下記は **111駅（DB全駅）** 時点の観察。

---

## 1. ズレ類型の分布 ＝ 街の「変わり方」の型（111駅）

供給（ゆっくり動く床）と需要（速く動く人の求め）のズレを類型化した、各型の駅数（複数該当あり）。

| ズレ類型 | 駅数 | 意味 |
|---|---:|---|
| **供給の慣性で残った床に新需要** | **71** | 空いた床に別の需要が流入（転用・再生） |
| 供給先行 | 33 | 計画的に床を作り、需要が後から追随 |
| 需要が去って供給だけ残存 | 27 | 主役需要が抜け、床・インフラだけ残る（衰退・空洞化） |
| 外来需要の再来型 | 17 | 国内需要が去った後、外（インバウンド等）から需要が戻る |
| 稼働時間の偏り | 14 | 空間でなく**時間**で床が遊ぶ（昼だけ/夜・休日は空） |
| 需要先行 | 5 | 需要が先に動き、供給が後追い |

**最大の発見**：**「供給の慣性で残った床に新需要」が圧倒的（71/111）**。東京の街の変化の主旋律は **「壊して作り替える」より「残った床を別の需要で埋め直す＝転用・再生」**。多くの駅が「需要が去って供給残存（27）」→「空いた床に新需要（71）」の2段で説明でき、衰退と再生はセットで起きる。

## 2. 類型の分布（111駅・統合後11種、ADR-0010）

住宅地型41 / オフィス街型28 / ターミナル商業型26 / **専門集積型26** / 興行・歓楽街型18 / **クリエイティブ転換型16** / 闇市あがり型12 / ブランド商店街型11 / 大学集積型9 / 門前町型9 / 官庁街型2。

→ 上位3つ（住宅・オフィス・ターミナル商業）が東京の「土台」。かつて長い尾に並んでいた「特定産業の集積型」（古書/サブカル/専門卸/町工場/大工場…）は **ADR-0010 で `専門集積型` に畳まれ、26駅でいきなり4位タイ**に立ち上がった。これは「特定産業が面的に集積した街」という単一メタパターンの強さを示す。**どの産業かは型ではなく 需要/アンカー タグで読む**（例: `専門集積型 × 需要=サブカル` ＝ 秋葉原・中野・下北沢）。

## 3. メタパターン群

### (a) クリエイティブ転換型（16駅）＝ 安い床が創造的消費の苗床になる
倉庫・問屋・工場・花街・闇市といった **「雑多で安い床」** が、EC化・産業移転で主役需要を失い、そこへ **カフェ・アート・クラフト・個人店** の新需要が入る。清澄白河（倉庫→現代美術/コーヒー）・蔵前（問屋→クラフト）・中目黒/恵比寿/天王洲アイル（工場・倉庫→おしゃれ消費）・神楽坂（花街→隠れ家飲食）・茅場町（証券ビル→リノベ）・大塚・西荻窪…。
裏のエンジンは2つの新ショック：**`リノベーション・床の再活用`**（物理的な転用）と **`ジェントリフィケーション・高級化`**（社会的な高級化）。

### (b) 稼働時間の偏り（14駅）＝ 空間でなく「時間」のミスマッチ
床は24時間そこにあるのに、需要が特定の時間にしか来ず床が遊ぶ。官庁街・オフィス街の **昼だけ／夜・休日は空**（霞ケ関・大手町・西新宿・中野坂上・虎ノ門・大崎）と、イベント施設の **公演日だけ満員**（水道橋・有明）。空間の埋め直し（再生）とは別軸の「時間の埋め直し」が課題になる街。

### (c) 埋立地の再開発サイクル
港・河岸・物流結節(27)・埋立・干拓地(16)というアンカーを持つ湾岸は、**「埋立で工業/倉庫の大区画 → 脱工業化で抜ける → 空いた巨大な床にタワマン・商業・オフィスが雪崩れ込む」** という同じ筋をたどる。豊洲・月島・東陽町・大崎・天王洲アイル・有明・お台場・田町・品川。

### (d) 供給先行の二極化（33駅）
「先に作る」街は二つに割れる：**私鉄沿線の郊外計画住宅地**（成城・大泉学園・石神井公園・多摩川/田園調布・自由が丘・経堂・成増・葛西…）と、**財閥・官の計画業務地**（大手町・神谷町・西新宿・虎ノ門）。郊外＝住む／都心＝働く。

### (e) 外来需要の再来（17駅）＝ インバウンド/再評価で外から需要が戻る
国内需要が細った下町・門前が、外国人観光や再評価で蘇る。浅草・柴又・門前仲町・上野・日暮里・亀有（コンテンツ聖地）・御徒町（アメ横）。

### (f) 専門集積クラスタ（＝ 類型 `専門集積型`、ADR-0010）
特定産業が面的に集積する型が繰り返す：古書（神保町）/サブカル（秋葉原・中野・下北沢）/楽器（御茶ノ水）/繊維（日暮里）/問屋（浅草橋・蔵前）/宝飾（御徒町）/町工場（蒲田・大田）/物流（流通センター・新木場）。これらは以前は産業ごとに別類型（古書店街型/サブカル集積型/専門卸街型/町工場集積型/大工場・産業発祥型）に分かれていたが、ADR-0010 で **単一の `専門集積型` に統合**した（産業名は型でなく 需要/アンカー タグが担う）。共通経路は **「アンカー×ショックで生まれた集積 → 主役需要を失い供給だけ残る → (一部は) クリエイティブ転換」**。

## 4. アンカーに映る「東京の出来かた」（上位）
港・河岸・物流結節27 / 寺社25 / 計画型(財閥・地主)23 / 工場・産業立地21 / 鉄道用地17 / 鉄道ターミナル16 / 埋立16 / 宿場・街道16 / 闇市13。
→ 東京は大きく **「水運・信仰・財閥計画・工業・鉄道・街道・闇市」** の7系統の初期条件から立ち上がっている、と読める。

## 5. 当初仮説の検証（ADR-0002 の例）
「知識産業はこういう立地で固まる」：神保町（古書）・御茶ノ水（大学・楽器・医療）・早稲田（学生・古書）が大学アンカーの周囲に知識・専門の帯を作る、が確認できた。
