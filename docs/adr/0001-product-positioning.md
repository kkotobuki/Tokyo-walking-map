# ADR-0001: プロダクトの位置づけ —「街版・思考シミュレータ」

- ステータス: Accepted
- 日付: 2026-06-16

## コンテキスト

「散歩する目的が欲しい」が出発点。既存アプリを見ると、観光系（スポット／グルメ／歴史紹介）も散歩系（歩数／GPS／達成率）も、結局は **答えを読む or 記録する** 止まりだった。
こちらが本当に知りたいのは「この街はなぜ発展したのか」「何で稼いでいるのか」「これからどう変わるのか」という **構造への問い**。

アプリの性格として3案を検討した:

- A: 街を知るためのアプリ（答えを読む）
- B: 街を観察して学ぶアプリ
- C: 街を分析して自分の仮説を蓄積するアプリ

## 決定

**B + C を核とする。** 本アプリは「答えを読む装置」ではなく、**街を歩きながら自分の仮説を立て、残し、史実で答え合わせする思考装置** とする。
位置づけは、既存の朝ニュース向け「思考シミュレータ」（判断関数＋意見生成モード）の **“街版”**。判断対象をニュースから「駅」に向け替えたもの。

史実・解説などのコンテンツ（A的要素）は目的そのものではなく、**仮説の「答え合わせ」用の報酬** としてループに組み込む。

## 根拠

- ユーザーの動詞が一貫して「考えたい／予測できたら／わかる」。受動的な消費ではなく能動的な思考が欲しい。
- 「仮説を立てる → 答え合わせ → 外れる → なぜ外れたか考える」というループが、単なる街歩きを **学びのゲーム** に変える。
- 既存資産（思考シミュレータ）の設計思想をそのまま流用できる。

## 結果

- (+) 主体的・反復的に遊べ、学びが深い。差別化も明確。
- (+) 既存の思考シミュレータの考え方を再利用できる。
- (−) 答え合わせのための史実コンテンツ整備にコストがかかる。
- (−) 「空のノート問題」（仮説を貯めるだけだと初期は何も返ってこない）を、答え合わせ機構で必ず回避する必要がある。

## 検討した代替案

- **A型（都市発展図鑑／読み物）**: 受動的で既存サービスとの差別化が弱い。
- **純C型（仮説の蓄積のみ、答え合わせなし）**: ただの日記になり、ゲーム性（ループ）が回らない。
