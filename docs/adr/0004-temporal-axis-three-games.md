# ADR-0004: 時間軸＝3つの別ゲームとして扱う（未来は「観点提供」に留める）

- ステータス: Accepted
- 日付: 2026-06-16

## コンテキスト

各駅で過去（なぜ発達したか）・現在（どんな街か）・未来（どう変わるか）を扱いたい。
だがこの3つは **認識論的に別物** であり、同じUI・同じ検証方法で均質に扱うと設計がボヤける。

## 決定

時制ごとに、扱い方とユーザー体験を分ける。

- **過去 = パズル（答えあり）**: 史実という答えが存在し隠れているだけ。仮説を立て → 史実で **答え合わせ**。
- **現在 = 観察**: 街の **成長度**（S字カーブ上のどこにいるか）を、歩いて目視で読む。
  - 観察プロキシ例: クレーン・再開発看板＝成長中／シャッター・空き店舗＝衰退 or 転換／チェーン比率高＝成熟・均質化。
- **未来 = 賭け（答えなし）**: 数年後にしか分からない。**計算で当てにいかず、考える「観点」を渡すに留める**。
  - 観点例: 「いまの政策が進んだらこの街はどうなるか」「この街にどんな商品がハマりそうか（需給ギャップ）」。
  - 政策シミュレーションは、**過去のショックと同じエンジンを順方向に回す** 形で表現する（仮想ショックの注入 → トレース）。

## 根拠

- 答えの有無・検証可能性が時制ごとに違うため、ループの作り方も変えるべき。
- 未来を計算で当てにいくと外す。道具の仕事は「補助線（観点）」を渡すところまで、と割り切ることで過剰約束を避ける。

## 結果

- (+) 各時制でUX／検証方法を最適化できる。
- (+) 未来について外さない（観点提供に徹する）。
- (+) 「商品がハマるか」という生成的な問い（理解の出口）を未来側に位置づけられる。
- (−) 時制ごとに別UIを実装するコストがかかる。

## 検討した代替案

- **3時制を同一UIで均質に扱う**: 認識論の差が潰れ、特に未来の不確実性を過信させる危険がある。
