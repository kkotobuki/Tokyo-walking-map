# ADR-0006: 駅ページの骨格はループ順で構成し、供給/需要を分けて「ズレ」を立てる

- ステータス: Accepted
- 日付: 2026-06-18

## コンテキスト

駅1ページの本文（ADR-0005）を、どんな骨格で書くかを決める必要があった。
最初の叩き台は**時系列の起承転結**だった。

> いつ何があった → それまではこんな状態 → それを機に人が集まってこうなった → だからこの街はこんな特徴 → 今こんな風潮、数年後どうなる？

これは読み物としては良いが、本アプリの目的（＝確定済み ADR）に照らすと負ける。するする読めてしまうこと自体が、ADR-0001 が拒否した「答えを読む装置」に逆戻りさせる。

## 決定

駅ページを、時系列の作文ではなく **ループの順番**で構成する。5部構成とする。

1. **観察のお題**〔見せる・答えは言わない〕: 「歩くと◯◯が目につくはず。今どのフェーズだと思う？」と問い、街を見させる。
2. **賭け**〔ユーザー入力・先に書かせる〕: 「なぜこうなった？」「数年後どうなる？」を**先に**書かせる。
3. **答え合わせ**〔隠す／めくる〕: 過去〜現在の本文。**供給の筋と需要の筋を分けて書く**（単線にしない）。あわせて、①の問いに正対した**直接の答え（お題の解説＝今どのフェーズか・なぜそうなったか）**を1本持つ。
4. **ズレ**〔本体〕: 供給と需要がいつ・どう食い違ったか。予兆・商品機会はここに宿る。
5. **未来＝観点**〔生成的・答えは出さない〕: 仮想ショックを1つ注入したら？／今の需給ギャップに何がハマる？

本文（ADR-0005）は③④に収まる。「だからこの街はこんな特徴」のように**現在の結論を本文で配ってしまわない**（それは①の観察で読ませる）。

## 根拠

時系列の起承転結は、確定済み ADR に対して次の通り反する。ループ順＋供給/需要分離で、いずれも解消する。

- **ADR-0001 違反**: 賭ける前に答え（過去〜現在）を全部読ませてしまう。→ ①②を先頭に出し、③を隠して「賭けてからめくる」順に直す。
- **ADR-0003 の本体（ズレ）が出る場所がない**: 供給単線の物語では、需要が章として存在せず、ズレが立たない。→ ③で供給/需要を分け、④でズレを独立させる。
- **ADR-0004 を殺す**: 「現在の特徴」を文章で配ると、街を見なくなる（現在＝観察のはず）。→ 現在は①の観察お題に回す。
- **ADR-0002 を妨げる**: 一因一果のきれいな弧は「1街＝1理由」という反システム的な思考を訓練する。→ 供給/需要の2筋＋ズレで、累積フィードバック（先後が決まらない）を表現する。

## 結果

- (+) ADR-0001〜0004 のすべてと整合する。
- (+) ズレ（ADR-0003 の目玉）が構造的に必ず立つ。
- (+) ⑤の「商品がハマるか／仮想ショック」で、未来を生成的な問い（ADR-0004）にできる。
- (−) 読み物としての気持ちよさは確実に落ちる（狙い通りだが、人によっては「面倒」になる）。
- (−) 供給/需要を分けて書く執筆負荷が、単線より上がる。

## 検討した代替案

- **時系列の起承転結（過去→現在→未来の作文）**: 読みやすいが、上記4点で目的に反するため却下。
- **読み物として全部見せる（ループ後回し／無し）**: ADR-0001 の中核ループを捨てることになるため却下。
