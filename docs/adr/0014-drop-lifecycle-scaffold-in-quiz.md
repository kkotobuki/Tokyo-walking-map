# ADR-0014: 行きフェーズの「成長/成熟/衰退/転換」4択足場を撤廃

- ステータス: Accepted
- 日付: 2026-06-23
- 関連: ADR-0013（クイズ体験＝自由入力）の行きフェーズを改訂する。

## コンテキスト

ADR-0013 では、行きの電車で表示する `観察お題` に「成長/成熟/衰退/転換」の4択を足場として添える設計だった。実際に触ってみて、この4択を不要と判断した。

## 決定

行きフェーズの **「成長/成熟/衰退/転換」4択足場を廃止**する。`観察お題` は **その街ならではの問いだけ** を表示し、ユーザーはそこに自由入力で仮説を書く（採点なし・書いてから読むハードロックは ADR-0013 のまま維持）。

## 根拠

- **4択に縛られて仮説が型にハマる**: ライフサイクルの4語を先に見せると、自分の観察より「どれを選ぶか」に意識が向き、街ごとの固有の手触りが痩せる。これは ADR-0013 が6択型当てを却下したのと同じ理由（「その街ならでは」を消す）。
- **足場が無くても問いが足場になる**: `観察お題` 自体が「その街ならではの問い」なので、別途4語を添えなくても書き出しの取っ掛かりになる。
- 成長/成熟/衰退/転換 という見方は、現在フェーズの **成長度の観察**（ADR-0004）の側で扱えばよく、入力時の選択肢として固定する必要はない。

## 結果

- (+) 仮説入力がより自由になり、街ごとの固有性が出やすい。
- (+) UI が単純化（選択UIが消え、問い＋自由入力だけになる）。
- (−) 書き出しの取っ掛かりが減る可能性。問い自体の質（`観察お題` の書き方）で補う。

## 検討した代替案

- **4択を別の足場（ヒント/観点）に差し替え**: 取っ掛かりは残るが、結局「与えられた枠で考える」点は同じ。まず素の問いだけで運用し、必要になったら別ADRで足場を再設計する。
