# アプリ仕様（実装用・1枚）

- 読者: 実装する本人。**Why は ADR-0012/0013 と product-brief.md**、本書は **What（画面・状態・データ写像・作る順番）** を引く場所。
- スタック: Expo（React Native / TS）／iPhone（Expo Go で確認）／データは Notion 直読み書き＋オフラインキャッシュ。

## 画面

1. **ホーム（駅選び）**
   - モードA「自分で選ぶ」: 駅名**検索**＋**タグ絞り込み**（区/路線/カテゴリ/需要/類型/ズレ類型＝全部出す）。一覧は全駅、**訪問済みは「行ったことある」明記**。
   - モードB「くじ」: **未訪問だけ**から**ランダム1駅**（一発勝負・引き直し無し）。ガチャ風に回って止まる。引いたら駅詳細＝行きへ。
2. **行き（クイズ）**: `観察お題` を表示＋**仮説の自由入力**。`仮説` に文字が入ると「答え合わせへ」解放（ハードロック）。
3. **現地**: `観察ポイント`（任意で `おすすめルート`）を表示。
4. **帰り（答え合わせ）**: 正解＝`お題の解説`/`供給の筋`/`需要の筋`/`ズレ`/`未来の観点` を表示＋自分の`仮説`を並置（○✕なし）。ズレ類型を「型でいうと」参考表示。**感想を入力**→保存→**訪問済み**。

## 状態機械（駅ごと）

`未着手` →（行きで`仮説`に文字入力）→ `答え合わせ待ち` →（帰りで`感想`記入）→ `訪問済み`
- ホームは状態で「次の一手」を出す（未着手＝行きのクイズ／答え合わせ待ち＝帰りに答え合わせ＋感想／訪問済み＝読み返し）。
- 状態の出典: `ステータス`（未訪問/予定/訪問済み）＋`仮説`/`感想` の有無。

## Notion 写像（data source e066cd64-d94f-44f1-acc5-e284ca84eec3）

- 読み（コンテンツ）: 駅名・区・路線・カテゴリ・アンカー・ショック・需要・類型・ズレ類型・観察お題・お題の解説・供給の筋・需要の筋・ズレ・未来の観点・観察ポイント・おすすめルート
- 書き（ユーザー記録）: `仮説`(text) / `感想`(text) / `ステータス`→訪問済み / `訪問日`→当日
- 型の単一ソースは `data/vocab.ts` / 写像雛形は `docs/station.ts`（`mapNotionPageToStation`）。

## オフライン（電車・トンネル対策）

- 読み: 起動時に Notion 取得→端末キャッシュ。圏外は直近キャッシュを表示。
- 書き: オンラインは即 Notion。圏外は端末に保存し、オンライン復帰時に同期（書きキュー）。

## 設定・秘密

- `NOTION_TOKEN` と DB ID はアプリが保持。`.env`/SecureStore 管理、**コミット禁止・直書き禁止**（CLAUDE.md / ADR-0012）。

## 作る順番（縦に薄く）

- **Step 1**: Expo 土台＋**1駅**を Notion から読んでフルループ（行き仮説→ロック解除→帰り正解→感想→訪問済み→Notion 書き戻し）。オンライン前提。iPhone(Expo Go)で完走。
- **Step 2**: ホーム（一覧・検索・facet絞り込み・訪問済み表示）＋くじ、全111駅。
- **Step 3**: オフライン（読みキャッシュ＋書きキュー）。
